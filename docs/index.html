Features

🤖

AI-Powered

Uses SpaCy NLP to automatically identify person names in your documents

📄

Word Documents

Works with .docx files - the most common document format

🎯

Names Only

Extracts only person names, filtering out places, organizations, and events

📖

Page Numbers

Tracks approximate page numbers for each name found

🔤

Alphabetical

Generates alphabetically sorted index, grouped by letter

⚡

Fast & Easy

One command to process any document in seconds
